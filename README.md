## 🚀 Featured Projects

### 🚗 AutoCompare Maroc

**Automotive comparison and decision-support platform for the Moroccan market.**

AutoCompare Maroc explores a more accessible way to compare vehicles by combining technical specifications, Moroccan market information and user-oriented decision tools.

**Key concepts**

`Vehicle Comparison` `Moroccan Market` `Decision Support` `Responsive UI` `Automotive Data`

**Main objectives**

- Compare vehicles clearly
- Present technical specifications
- Integrate Moroccan-market information
- Support budget-oriented decisions
- Simplify complex automotive information
- Provide a modern responsive experience

> Certain datasets, product logic and future commercial components are intentionally kept private.

### 🎯 Business Prospecting Platform

**Data-driven system for detecting and qualifying business opportunities.**

The platform transforms public business information into structured commercial opportunities through collection, auditing, qualification and follow-up.

**Workflow**

`Collect → Audit → Deduplicate → Qualify → Score → Follow-up`

**Main capabilities**

- Public business-data collection
- Digital-presence auditing
- Prospect qualification
- Opportunity scoring
- Duplicate detection
- Campaign history
- Commercial follow-up
- Prospect status management
- Local dashboard
- Excel exports
- Business-specific demo preparation

The objective is not simply to collect businesses, but to identify **actionable commercial opportunities**.

> Core scoring rules, commercial logic and selected production components remain private.

## 🚀 Getting Started

### Requirements

Make sure you have:

![Node.js](https://img.shields.io/badge/Node.js-Required-339933?style=flat-square&logo=nodedotjs&logoColor=white)
![npm](https://img.shields.io/badge/npm-Required-CB3837?style=flat-square&logo=npm&logoColor=white)
![Git](https://img.shields.io/badge/Git-Required-F05032?style=flat-square&logo=git&logoColor=white)

### 1. Clone

```bash
git clone https://github.com/zakariabatlim/Portfolio.git
```

### 2. Enter the project

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
